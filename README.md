# Rowen Pangilinan Portfolio

Static portfolio website for Vercel.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New Project**.
3. Import the repository.
4. Leave the framework preset as **Other** or **Static**.
5. Deploy.

No build command is required. The site runs from `index.html`.

## Edit Content

- Main page structure: `index.html`
- Styles: `styles.css`
- Project list and filters: `script.js`
- Resume download: `assets/Rowen-Pangilinan-Resume.pdf`
